—MINING — HOW A BLOCK IS MADE

Searched on the phone.
Sealed by the node.

01 — SIGNSign the mine

The wallet signs a mine transaction with Dilithium3 (ML-DSA-65).

02 — SEARCHProof of work

The phone searches ~20 bits. Difficulty retargets toward ~8 second blocks and stays between 18 and 24 bits.

03 — VERIFYNode checks

The node checks the signature, the nonce, and the supply cap before accepting anything.

04 — SEALBlock written

The node writes the block and the reward pays. Gossip relays it — the block is the payment.

First mine on an address pays the current block reward plus a one-time +1 bonus. Then the schedule halves as joined users grow.
